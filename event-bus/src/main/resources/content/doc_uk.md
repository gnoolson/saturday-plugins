Модуль `event_bus` використовується для обміну повідомленнями та дозволяє різним сценаріям взаємодіяти між собою напряму, без жорсткої прив'язки один до одного.

### Як це працює?

1. **Сценарій_1** підписується на обрану тему.
2. **Сценарій_2** публікує повідомлення в цю тему.
3. `event_bus` запускає **Сценарій_1** та передає в `Args` повідомлення, яке надіслав **Сценарій_2**.

Сценарій не може публікувати повідомлення в тему, на яку він сам підписаний!

### API
```lua
local eventBus = require("event_bus")

-- підписка на вказану тему
-- повертає true, якщо підписка успішна; false — якщо сценарій уже був підписаний
local subscribed = eventBus.on("event_name_1")

-- відписка від вказаної теми
-- повертає true, якщо відписка успішна; false — якщо сценарій не був підписаний
local unsubscribed = eventBus.off("event_name_1")

-- публікація повідомлення у вказану тему
-- повідомлення має бути асоціативною таблицею (table у форматі ключ-значення, не масив)
-- повертає кількість запущених сценаріїв
local recipients = eventBus.emit("event_name_1", {pi = 3.14})

-- отримання даних із повідомлення через Args сценарію
-- local pi = Args.pi

-- отримання інформації про активні підписки
local info = eventBus.info()

Output.print(info)
--[[ надрукує:
{
  "event_name_1" : [ "764f6190-c71d-4fe2-99f5-99c707a06cf1" ]
}
]]
```
