Модуль `locker` використовується для запобігання конкурентному доступу до ресурсів, оскільки Сценарії можуть виконуватися паралельно та читати або змінювати спільні дані.

Це досягається шляхом блокування потоків виконання в критичних секціях.
Використовується оптимістичне блокування. Допускається вкладене блокування.
Якщо блокування не буде знято до завершення виконання Сценарію, воно буде зняте автоматично після завершення його роботи.

##### Приклад

```lua
local Locker = require("locker")

local lockHandle = Locker.lockIds("id_1", "id_2", "id_n") -- спроба отримати блокування для вказаних ідентифікаторів; повертає table
-- local lockHandle = Locker.lockGlobal() -- спроба отримати глобальне блокування; повертає table
-- !!! ПОЧАТОК КРИТИЧНОЇ СЕКЦІЇ !!!





-- !!! КІНЕЦЬ КРИТИЧНОЇ СЕКЦІЇ !!!
lockHandle:close() -- знімає блокування
```
